# Проверка нового окна клиента — 2026-10-03

Новый интерфейс подготовлен в master для будущего updater-v1.0.1. Публичная версия остаётся **updater-v1.0.0**; версия исходной сборки пока тоже `1.0.0`, чтобы UI refactor не включал подготовку выпуска.

## Реализованные состояния

| Состояние | Основное действие |
|---|---|
| Первая установка | Установить и настроить |
| Исправная установка | Кнопки нет; «Всё готово» |
| ARK не найдена | Указать папку ARK |
| Интеграция отсутствует или изменена | Восстановить интеграцию Steam |
| Неполная установка, нет EXE/config либо локальных данных перевода | Восстановить установку |
| Исходные параметры не подтверждены | Восстановление отключено; объяснение безопасного сценария |
| Неоднозначный профиль | Выбор обязателен до установки/repair |

Один профиль показан текстом, несколько — ComboBox. Полные пути перенесены в tooltip. Сервисные действия находятся в ContextMenuStrip «Дополнительно», удаление отделено separator. Основная доступная кнопка является AcceptButton; удаление не назначается действием по Enter/Esc. Прогресс скрыт в покое, операции используют marquee и фактический прогресс загрузки.

## Проверки

- Полный .NET test suite: **137/137 PASS**, 0 пропусков. Добавлено 30 проверок состояния, локального чтения и реального WinForms layout/защиты preview.
- Тесты охватывают неполную установку, сохранённые/неизвестные исходные параметры, повреждённые config/state/VDF, несовпадающий PAK, контекстную доступность меню и запрет действий preview даже при ошибочно разрешённом состоянии кнопки.
- Макеты проверены программным масштабированием контролов на 100%, 125%, 150%: размещение в пределах родителей, высота русских подписей и ширина кнопок. Настройки масштаба Windows не изменялись; отдельная интерактивная проверка на физических мониторах с разным системным DPI не выполнялась.
- Реальный preview открыт через `Открыть предпросмотр.vbs`: новое окно показало найденные Steam/ARK, выбранный профиль, работающую интеграцию и перевод v1.0.0. Основной кнопки и полосы прогресса нет. Меню проверено; изменяющие действия отключены. Esc закрыл меню без операции.
- Предыдущий commit `39cea2111abbe3d7a8060a89008d5093895c63c6` сохранён: LocalLogger использует `DateTimeOffset.Now:O`. Его тест ISO 8601/локального offset/неизменности сообщения проходит. Машинные даты не изменены и остаются UTC.
- В одном предварительном полном прогоне прежний тест проверки PID дочернего процесса упал; отдельно и в двух последующих полных прогонах прошёл. Код проверки процессов не изменялся.

## Безопасность реального preview

`--ui-preview` обрабатывается до перенаправления на установленный EXE и очистки self-update. Открытие окна не создаёт LocalLogger-записей, каталогов и сетевых запросов. Все изменяющие команды блокируются и в меню, и в обработчике действий. Можно открыть уже существующий лог без создания нового.

До работы сохранены локальные контрольные суммы 9 файлов и регистрация HKCU. Установленный EXE, config/backup/state/log, PAK и ярлык сохранили SHA; Installed Apps registration не изменилась. Один живой Steam localconfig был перезаписан между начальным снимком и стартом preview: последняя запись **16:18:18 +03:00**, процесс preview создан **16:21:29 +03:00**. Это произошло до запуска preview. Интеграция сохранилась; записей защищённых файлов после старта preview не обнаружено. Отдельное сравнение после закрытия preview сохранено в ignored work.

Preview собран только локально, `win-x64`, self-contained, single-file, без trimming:

```text
work\client-preview\ASA-RU-Fix.exe
```

Открывать через `work\client-preview\Открыть предпросмотр.vbs` либо с аргументом `--ui-preview`. Не копировать этот EXE в установленную папку. Это не Release artifact.

ARK и DevKit не запускались. Реальные install/repair/uninstall не выполнялись. Installed v1.0.0, форматы LaunchOptions, автоматическая Steam-цепочка, алгоритмы обновления/атомарной замены/удаления, channel schemas и server automation не изменены. GitHub build/release workflows не запускались, Release/tag не создавались, client.json/stable.json/automation.json не записывались.

Пользовательская визуальная приёмка нового интерфейса остаётся следующим шагом перед будущим выпуском.
